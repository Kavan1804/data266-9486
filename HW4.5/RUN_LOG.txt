Step 2b: First GPU attempt (HW4a on the lab RTX 4090, Colab local Docker runtime) and fixes
Date: 2026-10-27 (UTC)
HW4a ran top to bottom. BERT training and the HF pipeline completed, but vLLM 0.31.0 failed twice:
  1. 22:54:40Z  RuntimeError: Could not find nvcc and default cuda_home='/usr/local/cuda' doesn't exist
     Traceback ends in flashinfer/sampling.py top_k_mask_logits -> flashinfer/jit/cpp_ext.py get_cuda_path,
     called from vLLM's start-up warm-up (warmup_kernels -> sampler -> flashinfer_sample).
     Cause: FlashInfer 0.7.0.post1 compiles its sampling kernel on first use, and the Colab runtime image
     has no CUDA compiler. Fix: VLLM_USE_FLASHINFER_SAMPLER=0 before vLLM starts (the benchmark is greedy,
     so the sampler backend doesn't change what is measured). It got past this error on the next attempt.
  2. 2026-10-28T01:05:13Z  ValueError: Free memory on device cuda:0 (9.28/23.99 GiB) on startup is less
     than desired GPU memory utilization (0.85, 20.39 GiB).
     Cause: a test cell added at the top of the notebook in Colab had already started a separate vLLM
     engine with gpu_memory_utilization=0.5 (about 12 GiB) in the same kernel, so the benchmark's engine
     could not get its 85%. (That Colab copy of the notebook, with its outputs, is commit 0323ebe.)
     Fix: no test cell in the run; restart the runtime so only one engine uses the GPU. The vLLM cell now also logs free/total GPU
     memory right before start-up, so this is visible in the run log.
Change of plan: the full run will be done on a T4 instead. The notebooks were changed to run on any single
CUDA GPU, adapting to the card they detect:
  - Serving dtype: bf16 on cards with native bf16, float16 otherwise (vLLM refuses bf16 on a T4).
  - Part B mixed precision: bf16 autocast with native bf16; fp16 autocast + torch.amp.GradScaler otherwise.
  - HW4.5 checks which card HW4a ran on and labels comparisons against HW4a as cross-card if they differ.
  - The KV-cache sweep records any error (not only OOM) and stops, instead of stopping Run All.
  - HW4a downloads a zip of its outputs at the end; HW4.5 asks for it in Colab if HW4a's files are missing.
  - Run labels use the detected card: [RTX 4090 RUN] on a 4090, [GPU RUN — <name>] on anything else.
