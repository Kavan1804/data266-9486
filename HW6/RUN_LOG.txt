Error:
  AttributeError: Can't get attribute 'seed_worker' on <module '__main__' ...>
  RuntimeError: DataLoader worker (pid(s) 6279, 6280) exited unexpectedly
Cause: macOS starts DataLoader workers with "spawn", and spawned workers cannot import
functions defined inside a notebook (seed_worker, RotSSL, TwoViews). Linux, which Colab uses,
starts workers with "fork", which copies the notebook process, so this only affects local
runs. The notebook itself was not changed. The local test copy set the start method to "fork"
to behave like Colab.
