Step 3: Smoke Test and Fixes
UTC Timestamp: 2026-11-17T18:41:00Z to 2026-11-17T19:12:08Z
Problems found and fixed:
  1. First smoke test: "DeadKernelError: Kernel died" after about 16 s. Running the cells as a script with
     python -X faulthandler showed a segmentation fault in background threads during the first CLIP forward
     pass on MPS. The same call worked in a small separate script. Removing the import lines one at a time
     showed that it only crashed when "import sklearn" came before "import torch" (two OpenMP runtimes).
     Fixed by importing torch / torchvision / transformers first, with a comment in the notebook.
  2. In the per-class accuracy chart the legend covered the deer bars and the 100% labels were clipped.
     Moved the legend above the plot and set the x-limit to 110.
Smoke test (HW11_SMOKE_TEST=1: 10 images per class, 500 CIFAR-10 images) then ran without errors. It took
25 minutes, almost all of it downloading CIFAR-10 from the Toronto server (about 120 KB/s), into HW11/data.
