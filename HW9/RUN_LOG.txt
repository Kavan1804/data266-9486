Step 0: Repository and Reference Inspection
UTC Timestamp: 2026-11-03T16:30:00Z (approx.)
Status: Read both demo notebooks in full. Demo_9_Stable_Diffusion.ipynb resizes FashionMNIST to
64x64, repeats the gray channel to 3 channels, normalizes to [-1, 1], encodes with the
stabilityai/sd-vae-ft-mse AutoencoderKL (latent_dist.sample() * 0.18215, latent [1, 4, 8, 8]),
decodes with latents / 0.18215, mixes noise into the latent as (1 - a) z + a eps, and trains a
tiny CNN to predict the clean latent. Demo_9_CFG.ipynb runs a class-conditional DDPM directly on
1x64x64 images: T = 1000, linear betas 1e-4 to 0.02, q_sample, sinusoidal TimeEmbedding,
ResidualBlock / SelfAttention / BottleNeck / Encoder / Decoder blocks (64-128-256 channels),
an 11-row label embedding (10 classes + null) added to the time embedding, label dropout 0.1,
Adam lr 2e-5, batch 1000, 50 epochs, and CFG sampling with w = 3. Neither demo was modified.
The full assignment text was taken from the Canvas screenshot (no PDF exists). Looked at HW7 and
HW8 for conventions (Step 0 personal parameters as the first code cell, a timestamped log()
helper writing results/run_log_raw.txt, figures/ results/ checkpoints/ folders, an environment
variable smoke-test switch, RUN_LOG.txt / METRICS.md / AI_USE.md). Personal parameter formulas
from HW1 (SEED = SID4, SLICE = SID4 % 1000, HP_ID = SID4 % 6, CLS_A = SID4 % 10,
CLS_B = (CLS_A + 1 + (SID4 // 10) % 9) % 10).
Conflicts and issues found:
  1. The assignment asks for self-attention at 16x16, but a 64x64 image gives an 8x8 latent,
     so a U-Net on it never reaches 16x16. Decision: resize to 256x256 -> 4x32x32 latent, U-Net
     32 -> 16 -> 8 -> 4 with attention at 16x16 (e2, d2) and in the 4x4 bottleneck.
  2. The demo ResidualBlock has no shortcut (it never adds its input back). A 1x1-conv
     shortcut was added.
  3. The demo drops labels per batch (torch.rand(1) < 0.1). The assignment does not say per
     image or per batch, so the demo's per-batch version was kept.
  4. The demo's training DataLoader is not shuffled and its test loss uses new random noise
     every epoch. The HW9 notebook shuffles and uses a fixed seed for the test loss.
  5. The assignment intro mentions cross-attention conditioning, but the detailed list says to
     combine label embeddings with the time embedding. The detailed list was followed.

find_spec check thought it was on Colab. The Colab check now looks for /var/colab/hostname (the same
